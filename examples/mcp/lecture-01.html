Start with a picture

Imagine a brilliant kid in a room full of locked doors.

The kid is the AI. The doors lead to GitHub, a database, a browser, or your company’s APIs. The kid can reason about what to do—but every door used to have a different handle, different rules, and a different instruction manual.

Before the bridge

Every app built its own custom connector for every tool. Add a new AI host, and the same integration work started again.

Lots of clever adapters. Almost no shared language.

The design question

Can tools describe what they can do once, in a way many AI applications can understand?

The idea, before the acronym

One shared doorway beats a pile of one-off keys.

Host

Server

Say it out loud

A 30-second interview answer

MCP is an open protocol that gives AI applications a standard way to discover and use external tools and data. Instead of every host writing a separate integration for every service, an MCP client connects the host to an MCP server that exposes capabilities in a shared shape. That makes integrations reusable—but the server and its permissions still need to be trusted and reviewed.
